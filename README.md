# A Jungle Full of Dinos 🦕

Gemütliches 2D-Wimmelbildspiel im Devcats-Stil: Finde alle **22 Dinos**, die im Zimmer versteckt sind!

▶️ **Jetzt spielen:** https://x4rinia.github.io/A-Jungle-Full-of-Dinos/

## Features
- 22 handgezeichnete Dinos zum Finden – gefundene Dinos werden grün eingefärbt
- Lupe als Hinweis (mit 5 s Cooldown)
- Zoomen & Verschieben (Maus, Mausrad, Buttons)
- Fortschritt wird automatisch im Browser gespeichert
- Soundeffekte (abschaltbar) & Konfetti beim Sieg

## Lokal starten
Reine HTML/CSS/JS-Seite ohne Build-Schritt – einfach `index.html` über einen beliebigen Webserver (z.B. Apache) ausliefern.
